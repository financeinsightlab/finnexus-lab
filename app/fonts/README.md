# Self-hosted fonts

These Latin-subset WOFF2 files keep the existing site font families available without a build-time Google Fonts request. They were sourced from Fontsource 5.3.0 packages and remain under their included SIL Open Font Licenses:

- Inter variable: `@fontsource-variable/inter` — see `LICENSE-Inter.txt`
- IBM Plex Mono weights 400 and 500: `@fontsource/ibm-plex-mono` — see `LICENSE-IBM-Plex-Mono.txt`
- Source Serif 4 variable normal and italic: `@fontsource-variable/source-serif-4` — see `LICENSE-Source-Serif-4.txt`
