- Spreadsheet, SQL, Python, BI, Data Quality, Case, Workplace, Capstone, Project, Assessment and Career systems
- Local SQL, Python and workbook-validation runtimes
- Personal roadmap, mastery, review, portfolio, artifact and publishing flows

## High-quality design elements already present

1. Every authored course chapter uses outcome → business relevance → analogy → detailed sections → worked example → practice → model response → interview prompt.
2. Progress is evidence-oriented: labs, cases, projects, assessments, artifacts, capstones and reviews are more valuable than opening a lesson.
3. Portfolio claims are explicitly constrained to truthful local evidence.
4. Local SQL, Python and XLSX workflows provide actual technical proof rather than only static content.
5. The platform distinguishes reviewing a course from meeting an evidence-based mastery gate.

## Remaining content-quality improvements

The curriculum is now functionally complete. The next content work should not be broad new levels; it should deepen practice variety:

- Add more randomized question variants per technical skill.
- Add sample solution artifacts after learner submission, not before.
- Add more public/synthetic datasets at different scales.
- Add BI dashboard image critique examples.
- Add model-answer comparison for written business cases.
- Add artifact reviewer feedback based on actual uploaded workbook/code/dashboard evidence.

## UX fixes applied after audit

- Sidebar receives an independent vertical scrollbar and no longer loses lower navigation items.
- Long course menus receive sticky, independently scrollable navigation.
- Long onboarding modal receives viewport-constrained scrolling.
- Personal Roadmap now exposes the learner's role, target timeline, study cadence, recommended start point and target evidence.
- The roadmap uses a horizontal milestone strip and a vertically scrollable 15-level path on smaller screens.

## Definition of top-level completion

The course is “top level” when the learner completes real evidence, not when the platform adds more static features:

1. Finish the 30-Day Launch Plan.
2. Complete and validate the Spreadsheet and Data Quality projects.
3. Complete real SQL/Python/BI evidence.
4. Attach artifacts, run Reviewer Mode, and publish only approved work.
5. Complete a capstone and one mock interview/case sequence.
6. Use the Weekly Review and Mastery Engine to close actual skill gaps.
