## 📘 Concepts

### 5.1 The five series traps (names = vaccines, arena law)

1. **Premature Commit** — locking the FIRST pattern that fits 4 terms, when a second-order truth rules (e.g., treating 3,6,11,18 as \"+3,+5++ chaos\" instead of n²+2). *Vaccine: one more machine row before committing; two pattern-witnesses minimum.*
2. **Two-Fit Panic** — two families both fit (5,11,17: AP+3 AND prime-gap-6) → frozen. *Vaccine: the SIMPLICITY LAW (NS3): lowest-order rule wins; if options list both answers, the options disambiguate which family they want — read them before re-solving.*
3. **Position Slip** — missing-middle or twin-split answered for the WRONG INDEX (answering the 8th when the hole is 7th). *Vaccine: sketch position numbers above the terms, EVERY time; it's a 3-second mega-vaccine.*
4. **Twin-Blindness** — running global machine on a braided series and calling the paper \"broken.\" *Vaccine: bump-tell recognition: diffs alternating weird-small? → split odd/even before any give-up thought.*
5. **Wrong-Term Overreach** — \"fixing\" the series at the FIRST dirty link instead of locating the shared culprit/double-link test. *Vaccine: NS4 protocol: dirty PAIR → shared suspect → substitution re-cleans BOTH links — or keep hunting.*

### 5.2 The 7-gate radar (recited, then internalized)

```
G1 diffs constant/straight? → AP / 2nd-order     G2 ratios constant/ladder? → GP / ×n
G3 ratio drift → ×n±k                            G4 near squares/cubes ±k → wardrobe
G5 bumpy diffs → SPLIT odd/even                  G6 names over math → primes ±k
G7 memory terms → sums (Fib / tribonacci / ×2±1-style sidekicks)
```
Narration drill (3 series, 45 s total): scan aloud, name the gate, solve, move. **You don't get faster by staring longer — you get faster by scanning in a fixed order.** 70% of exam series live in G1–G3.

### 5.3 Question-type triage

```
Next-term, clean family (G1–G3) ......... BANK first (~25–35 s)
Wrong-term protocol .................... GRIND second (~45–60 s; mechanical)
Twin/prime sums ........................ BANK if radar lands fast
Position-ops / growth monsters ......... PARK (>90 s cap; return with surplus)
```
Never let one stubborn series eat two easy series' time. Marks don't care about your relationship with the puzzle.

## ❓ Quiz

**Q1.** The 'Premature Commit' trap is vaccinated by:
- (a) Trusting the first pattern that fits
- (b) **Running ONE more machine row (or a second family-witness) before committing — 3,6,11,18 looks chaotic until second differences reveal the constant 2 underneath**
- (c) Answering bigger numbers
- (d) Skipping all pattern checks

**Q2.** 5, 11, 17 fits BOTH AP(+3) and prime-gap-6 families. The exam-correct tie-breaker is:
- (a) Panic and skip
- (b) **The SIMPLICITY LAW — the lowest-order rule wins (AP), and the OPTIONS disambiguate which family the setter intended; freeze is the only losing move**
- (c) Always pick primes
- (d) Multiply the rules

**Q3.** For braided (twin) series, the 3-second mega-vaccine before anything else is:
- (a) Bigger difference rows
- (b) **Sketch POSITION NUMBERS above the terms — twins (and position-slip traps) become visible instantly; the odd/even split then decides which sub-series owns the target position**
- (c) Reading backwards
- (d) Cubing terms

### ✅ Answers

1. **(b)** — two witnesses or no conviction: machine-row plus family sniff. Commit twice-fast beats commit once-wrong.
2. **(b)** — Occam pays marks. AP beats prime-exotics at equal fit; options resolve residual ambiguity. Your only illegal state is frozen.
3. **(b)** — position numbers are the world's cheapest vaccine: 3 seconds, kills twin-blindness and position-slips in one stroke.
